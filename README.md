# UniDorm

UniDorm is a dormitory management application with student and administrator areas for room discovery, room bookings, announcements, direct and group messaging, and payment-bill tracking.

## Project layout

- `frontend/`: Next.js 16, React 19, TypeScript, and Tailwind CSS.
- `backend/`: NestJS 11 REST API, Prisma 5, and PostgreSQL.
- `db/unidorm`: PostgreSQL custom-format database export from the original project. Keep a backup before restoring or importing it.

## Requirements

- Node.js 20.9 or newer (Node.js 22 LTS recommended).
- npm.
- PostgreSQL 14 or newer.

## Configure the backend

Open a terminal in `backend`:

```powershell
Copy-Item .env.example .env
npm ci
```

Edit `backend/.env` and set a working PostgreSQL connection, a private JWT secret, and an administrator registration key. Never commit this file.

Generate Prisma Client and apply migrations:

```powershell
npx prisma generate
npx prisma migrate deploy
```

Start the API:

```powershell
npm run start:dev
```

The API listens on port 3001 by default. The root endpoint at `http://localhost:3001/` is a public health check; all application routes require a bearer token except login and registration.

### Administrator registration

Student registration is public. Administrator registration requires the `ADMIN_REGISTRATION_KEY` value from `backend/.env`. Enter that key on the Admin registration tab. Admin IDs are generated by the backend.

For production, set a long, random `JWT_SECRET`, a private `ADMIN_REGISTRATION_KEY`, a production `DATABASE_URL`, and `FRONTEND_URL` to the exact frontend origin(s). Do not use the development JWT fallback in production.

## Configure the frontend

Open a second terminal in `frontend`:

```powershell
Copy-Item .env.example .env.local
npm ci
npm run dev
```

The default frontend API URL is `http://localhost:3001`. Set `NEXT_PUBLIC_API_URL` in `frontend/.env.local` when the API is hosted elsewhere. Restart the Next.js server after changing environment variables.

Open `http://localhost:3000`.

## Build and test

Backend:

```powershell
cd backend
npx prisma generate
npm run build
npm test -- --runInBand
```

Frontend:

```powershell
cd frontend
npm run build
npm run lint
```

## Main application capabilities

- Student registration and login using student IDs.
- Admin registration with a private setup key and generated admin IDs.
- Room catalogue and gender-appropriate room selection.
- Booking requests, admin approval/rejection, and booking history.
- Audience-filtered dorm announcements.
- Gender group chats and direct admin/student chat requests.
- Student-specific bill lists and admin bill creation.

## Payment note

The current payment workflow is a bill-status tracker. The student action records a bill as paid; it is not a payment gateway and does not process bank cards, PromptPay, or transfers. Integrate and verify a real payment provider before treating this action as proof of money received.

## Security notes

- API requests other than login/registration require a signed JWT.
- Administrator-only operations are enforced server-side.
- Student booking, bill, and chat access is restricted by the authenticated account.
- Password hashes are never returned by login.
- Configure secrets through local environment files, not source code.
