# UniDorm Student ID Format

UniDorm assigns a ten-digit login ID to each newly registered student.

| Positions | Meaning | Source |
|---|---|---|
| 1–2 | Admission academic year in the Thai Buddhist Era (for example, 69 for B.E. 2569) | Entered as part of the PSU-provided prefix |
| 3–8 | The student's existing campus/faculty/programme grouping digits | Entered from the student's own PSU ID |
| 9–10 | Registration sequence, allocated by UniDorm from 01 to 99 for each distinct eight-digit prefix | Generated by the backend in registration order |

Students enter the first eight digits of their PSU student number. UniDorm allocates the last two digits automatically. Different programmes and campuses can use different eight-digit prefixes; the application does not hard-code a Phuket Campus or Digital Engineering code.

The generated ten-digit number is a **UniDorm login ID**. It is not a substitute for, or a claim to recreate, the official PSU-issued student number. Students should continue using their official PSU number for university services.

The sequence is stored in PostgreSQL and allocated atomically, so two registrations using the same prefix cannot receive the same suffix. The migration seeds sequence counters from existing ten-digit student accounts and does not modify those accounts.
